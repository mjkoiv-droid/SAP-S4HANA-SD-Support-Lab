
# M5 - Incident, Problem and Root Cause Management

**Status:** Not started

## Objective

Investigate, resolve, and document realistic SAP SD application support incidents using structured troubleshooting, root cause analysis (RCA), corrective actions, and regression testing.

## Scope

- Incident classification, priority, impact, and escalation
- Sales order pricing failures
- Delivery and picking discrepancies
- Billing creation failures
- IDoc/interface processing failures
- Invoice output failures
- Authorization errors
- Incident versus problem versus service request
- Root cause analysis using 5 Whys
- Workarounds and permanent corrective actions
- Regression testing and incident closure
- Business communication and SLA considerations
