
# M8 - Authorization, Access Review, Segregation of Duties and Audit

**Status:** Not started

## Objective

Investigate SAP authorization issues, evaluate user access risks, assess segregation-of-duties (SoD) conflicts, and document audit-ready security controls.

## Scope

- Authorization failure investigation (SU53)
- User and role analysis (SU01/PFCG), if authorized
- SAP authorization concepts and effective privileges
- Least-privilege access management
- User-to-role access review
- Sales, Warehouse, Billing, and Support role assessments
- Segregation-of-duties (SoD) risk analysis
- Conflicting permissions and mitigating controls
- Access requests and approval workflows
- Change logs and audit evidence
- Periodic access review and sign-off
- SAP GRC concepts and limitations

## Planned Deliverables

- Authorization troubleshooting case
- User access review matrix
- Two SoD conflict assessments
- Least-privilege role request
- Audit evidence package
- Supporting SAP screenshots or clearly labeled simulations
